Support — Reisen

Last updated: August 2026

Reisen is an open-source app for personal trip management on iPhone, iPad, and Mac. There is no commercial support team — help is provided through the public GitHub repository.

Feedback and bugs

Use GitHub Issues for questions, feedback, and bug reports. In the app, open Settings → Feedback to create a public issue without a GitHub account.

Repository

Source code, CI status, and documentation: github.com/rosch100/Reisen

Privacy

Privacy Policy

Note

Reisen is not affiliated with Booking.com, Airbnb, Check24, Opodo, GetYourGuide, Traveloka, or other providers. Provider sign-in happens in embedded web views with your own account.
