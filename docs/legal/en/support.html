Support — Voyenna

Last updated: September 2026

Voyenna is a free app for iPhone, iPad, and Mac. The source code is CC BY-NC 4.0; you may use the app privately for free. Questions and feedback go through GitHub — or in the app under Settings → Feedback.

Feedback and bugs

In the app under Settings → Feedback: macOS releases and iOS Store/ad-hoc builds need no GitHub account; other builds open the GitHub form (account required). Email to reisenapp100@gmail.com becomes a public issue, also without a GitHub account. Issues from the app and Gmail ingress have no file uploads via the Issues API. Text attachments from Gmail ingress may appear as text in the public issue (pattern redaction); binary files and archives stay in the mailbox — please email sensitive screenshots to the same address. Exception: paste-import document emails with the marker reisen-paste-import-document are skipped by ingress; the original attachment stays in Gmail and does not become a public issue. GitHub web forms allow uploads, but they are public — send sensitive files by email as well.

You can also write on GitHub (GitHub account). App Store ratings and TestFlight feedback are welcome; they are not turned into GitHub issues automatically.
