Privacy Policy — Reisen

Last updated: August 2026

Controller

The Reisen app and this website are provided by Roland Schramme as an open-source project at github.com/rosch100/Reisen. For privacy questions, use the public GitHub issues: github.com/rosch100/Reisen/issues.

Summary

Reisen is a personal trip manager for iPhone, iPad, and Mac. Bookings stay on your device, optionally synced via iCloud. Sign-in with booking sites uses your own account with each provider. Reisen is not affiliated with Booking.com, Airbnb, Check24, Opodo, GetYourGuide, Traveloka, or other providers.

What data does Reisen process?

Trips and bookings (entered or synced by you)

  • Trip names, booking details, cancellation deadlines, manual entries
  • Stored in SwiftData on device; optional mirroring in your private iCloud container iCloud.de.reisen.Reisen

Provider sign-in (optional)

  • Sign-in on third-party websites in a WKWebView with your own account
  • Session cookies remain in the device web view cookie store
  • Optional (opt-in): email and password after password login in the app device Keychain — not for Apple / passkey / OAuth sign-in

Calendar and reminders (optional, opt-in)

  • With your permission: calendar events and reminders for cancellation deadlines in Apple Calendar / Reminders
  • Local notifications via Notification Center (no marketing pushes)

Technical settings

  • App settings in UserDefaults (e.g. enabled providers, calendar choice)
  • No tracking, no advertising ID, no sale of data

Feedback (optional)

If you send feedback or an error report, the app creates a public GitHub issue (text, app version, OS, device model, locale, optional provider, optional GitHub username for attribution). You do not need a GitHub account; the app uses an embedded issues-only token. Anyone can read the issue at github.com/rosch100/Reisen/issues.

iCloud / CloudKit

Sync uses Apple CloudKit in your iCloud account. Apple processes this data under the Apple Privacy Policy. You can delete local data or wipe iCloud data in the app settings.

Silent push notifications (iOS)

For CloudKit mirroring, iOS may receive silent background notifications (remote-notification). No visible remote push messages are sent to you.

Sharing with third parties

  • Provider websites: When you sign in, their privacy policies apply.
  • GitHub: Only if you send feedback or an error report in the app (public issues; no GitHub account required).
  • No analytics service, no ad network in the app.

Your rights

  • Delete data: local reset or “Also wipe iCloud data” in settings
  • Provider passwords: can be disabled in app settings; stored accounts removable in Keychain / Passwords app
  • Calendar / notification permissions: revocable in system settings

This website (GitHub Pages)

The information site at rosch100.github.io/Reisen is hosted via GitHub Pages. When you visit, GitHub, Inc. processes technical access data (e.g. IP address, browser type, timestamp, requested URL) in server logs — per the GitHub Privacy Statement, among other purposes for security and service operation.

  • Retention: per criteria in GitHub’s privacy statement (purpose, legal obligations, dispute resolution); no fixed period under our control
  • Recipients: GitHub, Inc. (USA) and GitHub’s subprocessors (e.g. cloud infrastructure)
  • International transfers: processing including in the United States; GitHub uses Standard Contractual Clauses (SCCs) as described in their privacy statement
  • No first-party cookies, analytics, embedded third-party scripts, or external fonts on our static pages
  • No tracking or profiling by us; no cookie banner required for static content alone (GitHub’s technical processing as above)
  • Legal basis: legitimate interest in operating a public project and information site (Art. 6(1)(f) GDPR)
